## Preview locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish with GitHub Pages
1. Create a new repository on GitHub (for example, `portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Before publishing
- Check the project links.
- Update the About text and skills if you want to reflect your exact experience.
- Add your preferred professional email or LinkedIn link if you'd like them shown in Contact.


Profile photo: `assets/mahalakshmi-photo.jpeg` is used in the Home section. Keep this file in the `assets` folder when deploying.
